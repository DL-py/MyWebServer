# 统一浅色 UI 重设计（welcome / login / register）

日期：2026-11-21
状态：待确认

## 目标

三张页面统一为一套清爽浅色风格，移除所有背景图片，去掉 login 对 Bootstrap 的依赖。页面仍然只是静态 HTML/CSS，由 `myhttp` 直接提供。

## 非目标

- 不修改 `.cgi` 脚本和表单提交逻辑。
- 不实现 CGI 执行（当前服务器只做静态文件服务）。
- 不引入前端框架、构建工具或网络字体。

## 方案

选定的做法：共用一份重写的 `styles.css`，三页使用同一套卡片布局和绿色主色（`#00B72E`）。被放弃的替代方案是深色极客风和极简文档风，原因是与现有配色差异过大或过于朴素。

### 设计系统

- 页面背景：浅灰绿 `#f3f7f4`。
- 卡片：白色，圆角 16px，最大宽度 520px（注册页 640px），轻阴影，上下留白。
- 主色：`#00B72E`，用于主按钮、焦点边框、链接。
- 字体：系统字体栈（不再加载 Google Fonts）。
- 输入框：浅灰底，圆角 10px，聚焦时绿色描边。
- 响应式：小屏卡片占满宽度，内边距缩小。

### 页面

1. `welcome.html`：标题 + 一句说明 +「登录」主按钮和「注册」次按钮。
2. `login.html`：标题「登录」，账号、密码字段，主按钮，底部「还没有账号？去注册」。
3. `register.html`：标题「注册」，字段为账号、密码、爱好、性别、自我介绍、地址；提交/重置按钮；底部「已有账号？去登录」。保留现有字段名，避免影响后端。
4. 三页统一加 `lang="zh-CN"`、`meta viewport`、`label for` 关联、`required` 和 `autocomplete`。

## 删除内容

- `web/image.webp`
- `web/background.webp`
- `web/bg-image.jpeg`
- `web/main.webp`（无任何引用）
- `web/bootstrap.min.css`（重设计后不再使用）
- `login.html` 中的 Google Fonts 引用

## 验证

- 三页均返回 200，HTML 中不再出现被删图片或 Bootstrap 的引用。
- 代码中 `grep` 确认无残留引用。
- 桌面和窄屏下布局不溢出（按宽度检查 CSS）。
